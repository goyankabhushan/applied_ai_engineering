# Applied AI Engineering

A practical learning roadmap for software developers who want to understand, integrate, and build applications powered by modern AI technologies.

The objective is to become job-ready for roles such as:

- Applied AI Engineer
- AI Application Engineer
- AI-enabled Software Engineer

**Learning philosophy:** Understand the concepts, learn how they work, implement them, and understand how to use them in real-world applications.

## Practical Implementation

A collection of practical implementations and experiments will be maintained in the `practical-examples/` directory.

The focus is on understanding concepts through working implementations rather than passive learning.

## Learning Approach

1. Understand what a concept is.
2. Understand why it exists.
3. Learn how it works.
4. Explore real-world applications.
5. Implement practical examples.
6. Understand engineering trade-offs.
7. Prepare for technical interviews.

## Career Objective

Develop practical AI engineering skills that complement existing software development experience and prepare for AI-focused engineering roles.
