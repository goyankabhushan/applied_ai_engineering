# 6. Retrieval-Augmented Generation

## Learning Goals

- Build an end-to-end RAG pipeline
- Evaluate retrieval quality separately from answer quality
- Improve relevance and traceability

## Core Concepts

- Document ingestion and normalization
- Retrieval and reranking
- Context assembly and citation
- Query rewriting and routing
- Evaluation datasets and relevance judgments
- Handling missing or conflicting evidence

## Practice

1. Build a simple document question-answering app.
2. Record retrieved chunks with every answer.
3. Measure recall and answer correctness on a test set.
