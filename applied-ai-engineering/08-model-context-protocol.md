# 8. Model Context Protocol

## Learning Goals

- Understand MCP clients, servers, resources, tools, and prompts
- Expose application capabilities to AI hosts
- Secure and operate MCP integrations

## Core Concepts

- MCP architecture and transports
- Resources and dynamic data access
- Tools and typed arguments
- Prompt templates
- Capability discovery
- Authentication, authorization, and auditing

## Practice

1. Create a minimal MCP server around local read-only data.
2. Connect it to an MCP-compatible client.
3. Log capability calls and test unauthorized operations.
