# 7. AI Agents & Agentic Workflows

## Learning Goals

- Choose deterministic workflows versus autonomous agents
- Design planning, tool, memory, and verification loops
- Control cost, latency, and failure modes

## Core Concepts

- Workflows, routers, and state machines
- Tool-using agents
- Planning and reflection
- Short-term and long-term memory
- Human-in-the-loop checkpoints
- Guardrails and termination conditions

## Practice

1. Implement a simple tool-calling loop with a maximum step count.
2. Add logging for every model and tool decision.
3. Create one retry, one blocked, and one successful task scenario.
