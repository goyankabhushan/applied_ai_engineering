# 9. Production AI Engineering

## Learning Goals

- Ship reliable, observable, and maintainable AI features
- Establish evaluation and safety gates
- Manage cost, latency, and model changes

## Core Concepts

- System architecture and service boundaries
- Prompt and model versioning
- Tracing, metrics, and structured logs
- Offline and online evaluation
- Rate limits and capacity planning
- Security, privacy, compliance, and red teaming
- Rollout strategies and incident response

## Practice

1. Add tracing to one AI application.
2. Create a versioned evaluation suite.
3. Define fallback behavior for timeouts and model outages.
