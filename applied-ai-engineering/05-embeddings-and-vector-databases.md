# 5. Embeddings & Vector Databases

## Learning Goals

- Understand embedding spaces and similarity
- Select and evaluate vector databases
- Design reliable chunking and indexing pipelines

## Core Concepts

- Embeddings and normalization
- Cosine similarity and distance metrics
- Chunking strategies and overlap
- Metadata filtering
- Index types and approximate nearest neighbor search
- Hybrid lexical and semantic retrieval

## Practice

1. Embed a small document collection.
2. Compare fixed-size and semantic chunking.
3. Build a search query and inspect returned metadata.
